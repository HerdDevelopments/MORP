What ships with MORP

⬡
Protocol Spec

RFC-style versioned document. Lifecycle, events, player, state, exports, callbacks, scheduler — all standardized and strictly defined.

v0.1 done
◈
Lua + TypeScript Adapters

Drop-in shims that map MORP's clean API onto FiveM's native calls. Full TypeScript types included. Zero runtime overhead.

v0.1 done
◎
Callback System

Async request/response between server and client. The pattern every FiveM developer rolls manually — now standardized.

v0.1 done
⬟
Resource Signing

Ed25519 keypair signing for resources. Adapter verifies on load. The integrity layer FiveM never shipped.

v0.2 wip
⬢
CLI Tooling

init, validate, build, sign. Full developer pipeline from scaffold to signed deployment in four commands.

v0.1 done
◉
Resource Registry

npm-style public registry for MORP resources. morp install. morp publish. The package ecosystem the community was always missing.

One API surface

Raw FiveM server.lua 
-- FiveM native (platform-coupled)
AddEventHandler('playerConnecting',
  function(name, kick, def)
    local src = source
    def.defer()
    local license =
      GetPlayerIdentifier(src, 0)
    Player(src).state.job = 'civ'
    def.done()
  end
)

AddEventHandler('playerDropped',
  function(reason)
    -- different event name
    -- different patterns
  end
)
MORP server.lua 
-- MORP (portable, consistent)
MORP.on('playerConnect',
  function()
    local src  = source
    local ids  =
      MORP.player.getIdentifiers(src)
    MORP.state.player(src)
      .set('job', 'civ')
  end
)

MORP.on('playerDisconnect',
  function(reason)
    -- same API, any platform
  end
)
